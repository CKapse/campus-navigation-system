# Campus Navigation System

A graph-based navigation system modeled on MIT-WPU 
campus buildings.

## Features
- Shortest path using Dijkstra's algorithm
- Minimum spanning tree using Kruskal's and Prim's
- BFS and DFS traversal
- Interactive menu

## Technologies Used
- C++
- STL (vectors, priority queue, maps)

## How to Run
g++ main.cpp -o navigation
./navigation
